# 😅 Exercice 09 - Builder Pattern

## Objectifs

- Comprendre et mettre en pratique la notion de "Builder Pattern".

## Mission

### Partie 1

Utilisez le concept de "builder pattern" afin de pouvoir créer des requêtes SQL. Il doit être possible de spécifier :

- Les colonnes à récupérer
- Les tables à lire
- Les conditions à respecter
- Uniquement **AND** ⚠️
- L’ordre des données souhaité
- Le nombre maximal d’enregistrements à retourner

Testez votre solution et affichez à chaque fois la requête SQL correspondante qui est produite. Testez-là !

### Partie 2

Adaptez ensuite votre builder afin de pouvoir créer les conditions des requêtes SQL également à l’aide d’un builder pattern. Les opérateurs suivants doivent être supportés :

- `=`
- `>`
- `<`
- `>=`
- `<=`
- `IN`

Testez votre solution et affichez à chaque fois la requête SQL correspondante qui est produite. Testez-là !
